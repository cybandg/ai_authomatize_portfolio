Генерация кода типовых задач: AI-агент + MCP + расширение VS Code

В проектах десятки однотипных задач: типовые фильтры и виджеты с предсказуемой структурой. Я собрал связку «расширение VS Code + MCP-интерфейс + AI-агент», которая узнаёт типовую задачу, генерирует код из сниппетов и открывает MR. Путь задачи сократился с ~2 рабочих дней до 15 минут.

Нажмите «Добавить задачу» и следите за потоком: труба заполняется, когда данные переходят между узлами.

Вручную~2 раб. дня

🎯 Контекст

  • Типовые фильтры и виджеты занимали ~2 раб. дня: boilerplate, тесты, ревью
  • Разработчики отвлекались от сложной логики на копипасту структуры
  • Нужен был инструмент внутри привычной среды, а не внешний сервис

🛠 Решение

  • VSC-расширение: генерация типовых фильтров и виджетов из сниппетов + LLM-адаптация
  • MCP-интерфейс: AI-агент вызывает расширение как инструмент
  • Агент сравнивает задачу с библиотекой паттернов и сам открывает MR

📈 Эффект

  • ~2 раб. дня → 15 минут на типовую задачу
  • Единый стиль кода и меньше ручных ошибок
  • Разработчики фокусируются на нестандартных задачах
Демо схематичное и игровое: реальные имена задач, MR и метрики заменены синтетическими, чтобы показать логику процесса, а не внутренние данные проекта.
